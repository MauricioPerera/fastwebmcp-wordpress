ENTENDERLO EN UN MINUTO

Tu sitio ofrece herramientas.
El agente aprende a usarlas.

WebMCP permite que una página web describa las acciones que un agente puede realizar. FastWebMCP añade esas herramientas a WordPress, tanto en el sitio público como en las pantallas de administración.

No incluye un chatbot ni un modelo de IA. Necesitas un agente y un navegador que puedan descubrir y ejecutar herramientas WebMCP. La disponibilidad depende de esa combinación.

PARA QUIEN USA EL SITIO

Encontrar contenido sin perderse.

“Muéstrame las entradas sobre diseño.”

El agente puede rellenar la búsqueda del theme y abrir los resultados normales de WordPress. Con el bloque Filtros de contenido, puede aplicar una consulta y categoría, y mostrar las coincidencias dentro del bloque.

↳ Los formularios y resultados se ven en la página. También puedes utilizarlos manualmente.
PARA QUIEN CREA CONTENIDO

Pasar de una idea a bloques reales.

“Añade un encabezado y un párrafo a este borrador.”

En Gutenberg, el agente dispone de herramientas para insertar, actualizar, mover y retirar bloques del documento visible. También puede trabajar con patrones y abrir plantillas según los permisos de tu cuenta.

↳ Los cambios se reflejan en el editor. Las operaciones disponibles dependen de tu cuenta y pantalla.
PARA QUIEN GESTIONA WORDPRESS

Una ayuda para las tareas del día a día.

“Prepara una nueva descripción para esta imagen.”

El agente puede consultar medios, preparar cambios de metadatos, gestionar comentarios o leer el estado del sitio. Para los ajustes compatibles, primero prepara el cambio y después lo aplica con una revisión válida.

↳ WordPress comprueba permisos en el servidor. El plugin no da privilegios adicionales al agente.

SIN TERMINAL PARA INSTALAR

Del ZIP a WordPress.

Descargar v0.6.0 ↓
  1. 1

    Descarga

    Guarda fastwebmcp-wordpress.zip. Para instalarlo en WordPress no necesitas descomprimirlo.

  2. 2

    Sube y activa

    Entra a Plugins → Añadir plugin → Subir plugin. Selecciona el ZIP, instala y activa.

  3. 3

    Elige una pantalla

    Abre FastWebMCP en administración, un editor de bloques o una página con un bloque de búsqueda.

  4. 4

    Conecta tu agente

    Usa un navegador y agente compatibles con WebMCP. Descubre las herramientas de esa página antes de pedir una acción.

Antes de empezar

Necesitas WordPress 6.5 o posterior, PHP 8.0 o posterior y permisos para instalar plugins. Prueba primero en una copia de tu sitio. Si no ves herramientas, comprueba la compatibilidad WebMCP de tu navegador y agente: instalar el plugin por sí solo no la habilita.

ANTES DE DAR EL PRIMER PASO

Preguntas frecuentes.

¿Necesito saber programar?

Para instalar el ZIP y usar los bloques incluidos, no. Para crear herramientas propias para tu theme o plugins necesitas JavaScript y, si ejecutan operaciones de servidor, PHP y conocimientos de permisos de WordPress.

¿Funciona con cualquier navegador o chat de IA?

No podemos dar por hecha esa compatibilidad. El navegador debe ofrecer WebMCP nativo y el agente debe poder descubrir y ejecutar sus herramientas. Esta versión se validó en un entorno local con un navegador compatible; no equivale a una certificación para todos los navegadores o proveedores de IA.

¿Qué pasa si no hay soporte WebMCP?

Las herramientas no se registran para el agente. Los formularios de búsqueda y filtros siguen disponibles para uso manual, y WordPress conserva su funcionamiento normal.

¿Tengo que poner un panel técnico en mi sitio?

No. Las herramientas del frontend actúan en los componentes de tu theme. El panel de laboratorio público es opcional para depuración y solo se muestra a administradores cuando se habilita.

¿El agente puede publicar o cambiar ajustes?

Existen herramientas para publicación, programación y ajustes compatibles. Requieren permisos de tu sesión y las comprobaciones del flujo correspondiente. Un visitante sin autorización no obtiene esos permisos por tener WebMCP.

¿Se puede instalar desde WordPress.org?

Actualmente se distribuye desde GitHub. Descarga el ZIP de la release e instálalo manualmente desde WordPress. La versión disponible es 0.6.0.

¿Es gratuito? ¿Dónde reporto un problema?

El plugin es gratuito y su código usa licencia MIT. Puedes revisar el código o abrir una incidencia en GitHub. El servicio de IA que elijas puede tener sus propios costes y condiciones.
